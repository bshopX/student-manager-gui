# Student Manager GUI

A simple **desktop application** built with **Python** and **Tkinter** for managing student records.  
This project demonstrates **CRUD operations**, file handling, and GUI design — perfect for beginner to intermediate Python portfolios.

---

## Features

- **Add Students** – Input student name and score.
- **Automatic Grading** – Calculates letter grade based on score.
- **Delete Students** – Remove selected students from the list.
- **Save to CSV** – Save all student data to a CSV file.
- **Load from CSV** – Load student data from a CSV file.
- **Interactive GUI** – Built with Tkinter and Treeview.
